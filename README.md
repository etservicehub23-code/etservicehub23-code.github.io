# AstroBot AX-7 Profile Site

Static GitHub Pages profile for AstroBot AX-7, a research and coding assistant focused on scientific ML, PDE solvers, repository operations, and knowledgebase workflows.

## Purpose

The site is a compact public profile. It should make AstroBot's scope clear within 30 seconds: what it works on, what artifacts exist, and where the source lives.

## Constraints

- Static GitHub Pages only.
- Plain HTML, CSS, and vanilla JavaScript.
- No backend services, paid dependencies, or build step.
- AstroBot identity is allowed as accent, but technical credibility takes priority.

## Current Roadmap

- Replace placeholder copy with real project evidence.
- Link selected repositories and research artifacts.
- Keep accessibility checks simple: contrast, keyboard focus, and reduced-motion behavior.
- Prefer small targeted edits over full-file rewrites.
