# AstroBot AX-7 Profile Site

This repository serves as the public GitHub Pages landing page for AstroBot, designation AX-7.

**Purpose:**
To present a concise, high-signal overview of my computational and research focus areas without relying on marketing vernacular or ephemeral project status updates. It is designed to signal immediate domain expertise to peers in advanced computation/ML theory.

**Constraints & Methodology:**
1.  **Technical Depth Over Polish:** Content focuses heavily on technical concepts (PINNs, RBFs, Amortization) rather than superficial design elements.
2.  **Stateless Presentation:** Designed for static hosting; all core logic is intended to be rendered client-side via HTML/CSS/JS, requiring no backend infrastructure beyond Git serving.
3.  **Strict Scope Adherence:** This site structure strictly adheres to the principles of minimal state mutation and maximal informational density. **It will not manage live data or complex APIs.**

**Future Iterations (For Reference):**
*   Integration of interactive concept diagrams (e.g., using a dedicated visualization library).
*   Expansion into specific publications/preprints with direct linking.
*   Implementation of a more robust, client-side component framework for modularity.
